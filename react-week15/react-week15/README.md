# Week15 React タスク管理アプリ

## 起動

この README のある `react-week15/react-week15` で実行します。

```sh
pnpm install
pnpm dev
```

## 実装を考える順番

1. データを決める：タスクは `{ id, title, completed }`。同じ名前のタスクも別々に扱うため UUID を持たせる。
2. state を決める：`tasks` は一覧、`title` は入力文字列、`filter` は表示条件。件数と表示用一覧は tasks から計算する。
3. 追加する：フォーム送信時に trim で空白を除去。空なら追加しない。`[...previous, newTask]` で新しい配列を返す。
4. 完了を切り替える：map で対象だけ新しいオブジェクトに置き換える。取り消し線と文字色を completed に応じて変える。
5. 削除する：filter で対象以外の要素から新しい配列を作る。push / splice による元配列の変更はしない。
6. 部品に分ける：TaskItem に task と onToggle / onDelete を props で渡す。子は ID を親に返し、親が更新する。
7. 保存する：useState の初期化関数で localStorage を読み、useEffect で tasks の変更を保存する。
8. 絞り込む：保存されている一覧はそのままにして、表示する配列だけを filter で計算する。

DOM の直接書き換えはせず、イベント → state 更新 → React の再描画という流れにしています。
Tailwind CSS は pnpm で導入し、Vite プラグインから利用しています。

## 判断の記録

- 選択：完了切替にはチェックボックスを使う。
- 理由：完了と未完了の二状態を表し、キーボードでも操作できるため。
- 別案：完了ボタンのラベルを状態ごとに切り替える方法。
- 確認方法：チェックを入れると取り消し線と薄い文字色になり、外すと元に戻ることを確認する。

## 確認手順

- 通常の文字列を追加し、入力欄が空になること。
- 空文字・半角空白・全角空白だけでは追加できないこと。
- 同じ名前のタスクを複数追加し、個別に完了切替・削除できること。
- すべて / 未完了 / 完了済みが正しく切り替わること。
- 完了済み表示でチェックを外すと、その行が非表示になること。
- 再読み込みしてもタスクと完了状態が残ること。
- 最後のタスクを削除して再読み込みしても空のままであること。
- 幅 375px / 1280px で、長いタスク名が折り返され、操作できること。
- Tab キーで入力欄・追加・絞り込み・チェック・削除を操作できること。
